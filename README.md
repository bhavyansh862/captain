# Hello, Captain! 🚢

A simple Docker project using the Alpine Linux image.

## Dockerfile

The Dockerfile uses `alpine:latest` as the base image and prints:

```text
Hello, Captain!
```

## Requirements

* Docker installed
* Git installed
* GitHub account

## Build the Docker Image

```bash
docker build -t captain .
```

## Run the Container

```bash
docker run --rm captain
```

## Expected Output

```text
Hello, Captain!
```
